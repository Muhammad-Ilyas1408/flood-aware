# Flood-Aware

AI-powered Flood Decision Support System for the Swat River Basin.

## Overview

Flood-Aware is an AI-assisted decision support system that combines:

- Flood Forecasting
- GIS Spatial Analysis
- Retrieval-Augmented Generation (RAG)
- LangGraph Decision Agent

to provide grounded flood-risk assessments and actionable recommendations for disaster management authorities and local communities.

## Key Features

- Flood situation analysis
- Population exposure estimation
- AI-powered decision support
- Interactive chat assistant
- Scenario simulation
- English and Urdu responses

## Technology Stack

- Python
- FastAPI
- Streamlit
- LangGraph
- LangChain
- OpenAI / Gemini
- FAISS / ChromaDB
- GeoPandas
- Rasterio
- Shapely
